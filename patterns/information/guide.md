# 情報設計 — 原理（蒸留済み）

最終更新: 2026-09-28

## 画面主題と着席目的を一致させる

- 各画面の **見出し・コピー・主要 CTA** は、そのセッションでユーザーが何をしに来たかと一致させる
- 副次機能（設定・シェア・課金導線）は主題を **奪わない位置** に置く
- 出典: [idesho-dopamine-prediction](../../references/2026-08-24-idesho-dopamine-prediction-vs-reward.md)

## フォームは入力種別ごとに専用部品

- テキスト・通貨・パスワード・タグ・日付範囲・レンジなど **型ごとに UI を分ける**
- ラベル浮上・強度バー・ロケール対応など、**バリデーション前の入力支援** を部品内に閉じ込める
- 出典: [SwiftPieces](../../references/2026-09-27-swiftpieces.md)

## リストは行アクション + ページング一体

- フィード・タスク・追跡 UI は **行スワイプ・チェック・ステータス列** を行コンポーネントに内包する
- 長い一覧は **async 無限スクロール** で段階読込し、空/エラー/末尾は状態 UI で切り替える
- 出典: [SwiftPieces](../../references/2026-09-27-swiftpieces.md)

## 絞り込みはカウント付きチップ

- フィルター候補は **件数付きチップレール** で横スクロールし、選択状態を一目で示す
- 「すべて」と特定条件の **排他/複数選択** ルールをチップ UI 上で統一する
- 出典: [SwiftPieces](../../references/2026-09-27-swiftpieces.md)

## 主要ナビは親指圏 + スクロール連動

- タブ代替は **フローティングドック** 等、親指の届く位置に主要セクションを置く
- セグメント + ページングは **スクロール追従タブ** で現在位置を同期する
- プロフィール・設定系は **ストレッチヘッダ** で一覧とヒーローを 1 画面にまとめる
- 出典: [SwiftPieces](../../references/2026-09-27-swiftpieces.md)

## 破壊的操作と権限は専用シート

- 削除・送金等の確認は **専用シート/カード** で二段確認し、本画面から切り離す
- カメラ・通知等の **権限リクエスト前** に、許可理由を説明するシートを挟む
- 出典: [SwiftPieces](../../references/2026-09-27-swiftpieces.md)

## メディアは一覧・全画面・Stories を分ける

- ギャラリーは **奥行きカルーセル** と **ピンチ/パン全画面** を用途で使い分ける
- 時系列ストーリーは **セグメントストリップ + 自動進行** を 1 パターンに閉じる
- 出典: [SwiftPieces](../../references/2026-09-27-swiftpieces.md)

## KPI はライブ更新 + スクラブ探索

- ダッシュボード数値は **スプリング付き更新** で変化を伝え、カウンター風表示で「増えた感」を出す
- 時系列データは **スクラブ可能チャート** で探索し、詳細は触覚/ツールチップで補う
- 出典: [SwiftPieces](../../references/2026-09-27-swiftpieces.md)

## AI 入力は候補チップ + コードブロック

- プロンプト入力には **候補チップ行** を載せ、初回/再訪問の開始摩擦を下げる
- AI 返答内のコードは **折りたたみ・ハイライト・ストリーミング** 対応ブロックで読みやすくする
- 出典: [SwiftPieces](../../references/2026-09-27-swiftpieces.md)

## 結果画面は比較軸を絞る

- セッション結果は **本人 vs 過去の自分** 等、意味のある比較軸を **最大 3 行** に絞る
- 改善幅には **閾値**（例: 10% 以上）を設け、小さなノイズを「伸び」として見せない
- 出典: [dopa-drill](../../references/2026-09-27-dopa-drill.md)

## 誤答支援は段階的ヒント

- 1 回目は再挑戦、**2 回目でヒント**、**3 回目で途中式** など、答えの丸写しに至る前の足場を段階提供する
- ヒントは **問題の構造** を示し、正解文字列のコピペにならないようにする
- 出典: [dopa-drill](../../references/2026-09-27-dopa-drill.md)

## 製品内ツアーは UI が語る

- 初回/再表示ツアーは **スポットライト + 説明カード** で UI 要素を指し示す
- マスコットは **指差し・表情のみ** — 台詞は UI カードが持つ（GK onboarding の「到達」とは別層）
- 配置は **障害物回避**（マスコット・ラベル被り計算）で読みやすさを保つ
- 出典: [dopa-drill デザイン分解](../../references/2026-09-27-dopa-drill-design.md)
