# コアループ設計 — 原理（蒸留済み）

最終更新: 2026-09-29

## 報酬粒度

- 完了（1 問題・1 セッション）だけだと、ドーパミン的フィードバックが遅い
- **操作単位**（1 マス入力、1 行保存、1 タップ）で小さな正解フィードバックを返すと、単調作業が「連鎖」になる
- 出典: [dopa-drill](../references/2026-09-27-dopa-drill.md)

## セッション内エスカレーション

- 同じ行為でも、**時間経過・進行度に応じて**演出・音・テンポ・視覚密度を上げると、1 セッションにクライマックスができる
- 数式例（dopa-drill）: 演出強度を問題 index の累乗曲線で単調増加させ、BGM BPM と連動
- 出典: [dopa-drill](../references/2026-09-27-dopa-drill.md)

## 失敗は連鎖を切るだけ

- ゲームオーバー・報酬剥奪・演出リセットは離脱を招きやすい
- 誤答は「おしい」+ ヒント + コンボのみリセット、など **進行と蓄積は維持** する設計が教育・習慣系に向く
- 出典: [dopa-drill](../references/2026-09-27-dopa-drill.md)

## 高報酬は opt-in

- 全員に高強度モードを強制すると挫折が増える
- 一定条件（例: 80% 正解率）を満たした人だけ **エクストラ** を選べるようにする
- 出典: [dopa-drill](../references/2026-09-27-dopa-drill.md)

## 2–3 回目が離脱壁

- **2–3 回目** が最大の離脱ポイント — 初回 80 点（habit）のあと、ここで「前より微妙」を防ぐ
- 4–5 回目の習慣化フェーズに届くまで、**変化と安定** のバランスを意識する
- 出典: [yokubo-no-kpi](../references/2026-09-29-yokubo-no-kpi.md)

## 地雷回避（減点・失望を防ぐ）

- 2 回目の **減点・バグ・期待外れ・演出の盛り下がり** は離脱の地雷 — 非惩罚設計と整合させる
- 「前回より悪い体験」を **設計上起こさない** ことを 2–3 回目の primary チェックにする
- 出典: [yokubo-no-kpi](../references/2026-09-29-yokubo-no-kpi.md)

## 美化記憶 — 最後の印象が次回期待値

- 離脱後、ユーザーは **良かった部分だけ** 記憶する — セッション **終了直前の印象** が次回の期待値を決める
- 失敗で終わる・責めで締めるより、**小さな前進や余韻** で終了させる（クリフハンガーと両立可）
- 出典: [yokubo-no-kpi](../references/2026-09-29-yokubo-no-kpi.md)

## 数値目標は前向きに

- 歩数・ストリーク・デイリー達成等の **数値目標** は行動を駆動するが、**未達の損失表示・責め** は感情体力（habit）と衝突する
- 「足りない」感覚は **前向きな CTA**（あと 1 問、今日の 3 つ目）に変換し、減点型 KPI にしない
- 出典: [irresistible](../references/2026-09-29-irresistible.md)

## フロー帯の維持

- 挑戦とスキルのバランスが取れた **没入帯** — 退屈（易しすぎ）でも不安（難しすぎ）でもないゾーンを維持する
- 明確な目標 + 即時 FB + 適度な難易度（progression のビギナーズラックと連動）
- 意図的にフローを壊して離脱させる場合は **stopping rules**（habit）とセットで設計する
- 出典: [irresistible](../references/2026-09-29-irresistible.md)

## クリフハンガー（未完了が再開を促す）

- **未完了・未解決**（あと 1 ステージ、次の章、デイリー 2/3）が記憶に残り、再開を促す — ツァイガルニク効果
- セッション終了時に **自然な停止点** を残す。habit の復帰トリガーとしても機能する
- 出典: [irresistible](../references/2026-09-29-irresistible.md)

## 供給サイクルでテンポを設計

- 報酬・FB の **供給間隔** が体験のテンポを決める — 短いほど単調作業が連鎖し、空けるほど期待が溜まる
- 操作単位 FB と整合 — セッション目的（短 burst vs 長 immersion）に合わせて間隔を選ぶ
- 出典: [watanabe-manga-pacing](../references/2026-04-07-watanabe-manga-pacing-dopamine.md)

## 快感は予測のリズムにある

- ドーパミン的快感は **報酬瞬間** だけでなく **届く前の予測** にも置ける — 次の FB までのリズムを設計する
- ハック型（刺激不足ループ）と傾聴型（予測を満たす）では **設計手法が異なる** — プロダクトの倫理・領域に合わせて選ぶ
- 出典: [idesho-dopamine-prediction](../references/2026-08-24-idesho-dopamine-prediction-vs-reward.md)
