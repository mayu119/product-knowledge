# core-loop — コアループ・セッション構造

1 回の利用で何が起き、どこで快感・達成感が生まれるか。

## 読む順

1. この README
2. `guide.md` — 蒸留済み原理
3. `candidates.md` — 未蒸留候補

## 典型の問い

- 報酬は「完了」単位か「操作」単位か
- セッション後半ほど盛り上がる設計があるか
- 失敗でループが死ぬか、続けられるか
- 高報酬は opt-in か強制か

## 使い方

1 セッションの構造を決める前に `guide.md` を **チェックリスト** として読み、2–3 回壁・フロー帯・非惩罚など Logic レイヤの抜けを埋める。
