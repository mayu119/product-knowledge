## アプリ同定

| 項目 | 内容 |
|---|---|
| 名称 | **yatta!**（yatta! Cute To-Do List & Tasks） |
| カテゴリ | 生産性 / ToDo・習慣 |
| プラットフォーム | iPhone（iOS 17+）、Mac（Apple Silicon）、visionOS |
| 開発 | Honda（ソロ）、NeuroKit AI ブランド |
| App Store ID | `6773757652` |
| ウィジェット | 小・中・大 3 サイズ（大はカスタム画像対応） |

**デザイン言語（一言）**: **ダークミニマル × 1 アクセントオレンジ × うさぎマスコット**。機能は「今日・あとで・いつか」の 3 分類だけに絞り、ウィジェット上で完了まで完結させる。

---

## ウィジェット前提

| 仮定 | 根拠 |
|---|---|
| **Medium（systemLarge 相当）** 正方形に近い | ヘッダ + 複数行リスト + 底セグメントが縦に収まる |
| iOS WidgetKit | 角丸・セーフエリア・ダークテーマ |
| インタラクション | タスク行タップで完了、+ で追加、セグメントでリスト切替 |

---

## 1. カラーシステム（hex 推定）

| トークン | 推定値 | 用途 |
|---|---|---|
| `--widget-bg` | `#1C1C1E` | ウィジェット全面 |
| `--surface-raised` | `#2C2C2E` | 非アクティブセグメント・ノッチ周り |
| `--accent` | `#F58233` | ＋ボタン、アクティブタブ、完了チェック |
| `--text-primary` | `#FFFFFF` | タイトル・未完了タスク |
| `--text-secondary` | `#8E8E93` | 件数「1」 |
| `--text-completed` | `#B86A3A` 〜 `#C47850` | 完了タスク（彩度を落としたアクセント系） |
| `--checkbox-stroke` | `#636366` | 未完了リング |
| `--mascot-watermark` | `rgba(255,255,255,0.06)` 〜 `0.10` | 中央うさぎシルエット |

**原理**: 背景は **iOS システムダーク 1 段**、インタラクションは **オレンジ 1 色** に集約。完了テキストだけアクセントを desaturate して「消えたが残っている」感。

---

## 2. タイポグラフィ

| 役割 | 推定 | サイズ感 |
|---|---|---|
| セクションタイトル「今日」 | SF Pro / Hiragino Sans、Semibold | ~17–20 pt |
| 件数 | Regular、secondary 色 | ~15 pt |
| タスク行 | Regular | ~15–17 pt、行間 ~1.35 |
| セグメント | Medium | ~13–15 pt |

- 日本語 UI（今日・あとで・いつか・掃除する・本読む）
- **原理**: ウィジェットは **1 ウェイト差 + 色差** だけで階層。装飾書体なし。

---

## 3. 角丸・スペーシング

| 要素 | 推定 |
|---|---|
| ウィジェット外周 | `border-radius: 28–32px`（OS ウィジェット標準） |
| ＋ CTA | 角丸正方形 ~36–40px、`radius ~10–12px` |
| セグメントコンテナ | 全幅 pill、`radius ~22–24px`、高さ ~36–40px |
| アクティブセグメント | 内側 pill、左右 inset ~3–4px |
| パディング | 水平 ~16px、ヘッダ上 ~12px、リスト〜セグメント間 ~8–12px |
| チェックボックス | 直径 ~22–24px 円 |

## 4. コンポーネント inventory

### ヘッダ行

| 位置 | 要素 |
|---|---|
| 左 | 「今日」+ グレー件数 |
| 中央上 | **ノッチ型マスコット**: 上辺を突き破る円形リセス、中に 3D 風白うさぎ |
| 右 | オレンジ **＋** ボタン（白アイコン、太め stroke） |

### タスクリスト

| 要素 | 未完了 | 完了 |
|---|---|---|
| チェック | グレーアウトライン円 | オレンジ fill + ダーク ✓ |
| ラベル | 白 | くすんだオレンジ/茶 |
| 背景 | 中央に **大型マスコット watermark**（リスト背後） | 同左 |

### 底セグメント（3 タブ）

| タブ | ラベル |
|---|---|
| 1 | 今日（アクティブ = オレンジ pill） |
| 2 | あとで |
| 3 | いつか |

非アクティブ: `#2C2C2E` 上に白文字。**pill-in-pill** 構造。

---

## 5. 状態設計

| 状態 | 視覚 |
|---|---|
| 未完了タスク | 白テキスト + グレーリング |
| 完了タスク | オレンジチェック + ミュートテキスト（打ち消し線なし） |
| アクティブタブ | オレンジ fill + 白ラベル |
| 非アクティブタブ | ダークグレー + 白ラベル |
| 空リスト（推定） | watermark マスコットが主役、CTA ＋ が目立つ |

アプリ本体では完了時にキャラが「やった！」と祝う — ウィジェットは **チェック色変化** で同系の達成フィードバックを縮小再現。

---

## 6. マスコット用法

| 用法 | 実装 |
|---|---|
| **ノッチアンカー** | 上辺中央、ブランドの「顔」 |
| **Watermark** | リスト背面、低 opacity シルエット — 空白でも寂しくない |
| 表情 | ウィジェット静止画ではニュートラル/微笑 |

**原理**: 同一キャラを ** focal（小）+ ambient（大）** の 2 スケールで使い、情報密度を下げない。

---

## 7. PK パターン mapping

| PK レイヤ | この UI が支えること |
|---|---|
| **visual** | ダーク + 1 アクセント、pill セグメント、マスコット watermark |
| **information** | 3 分類のみ — ウィジェット上で「いつやるか」だけ選ばせる |
| **habit** | 「今日」タブ固定 + 朝夜リマインド（アプリ側）で日次リズム |
| **feedback** | チェック即時色変化 → アプリ内祝祭へ橋渡し |

---

## 横断原理（widget 一般化）

1. **アクcent 1 色ルール** — CTA・選択・完了が同色で「触った/終わった」が一目
2. **セグメント 3 つ上限** — ウィジェット幅ではタブを増やさない
3. **完了 = 彩度ダウン** — 打ち消し線より「温かい過去」色
