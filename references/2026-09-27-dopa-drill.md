# ドパドリル（dopa-drill）— 体験・快感設計の分解

- 出典: https://github.com/grmchn/dopa-drill
- 公開版: https://dopa-drill.tanosix.com/
- 仕様: リポジトリ `docs/SPEC.md`（数式・閾値まで公開）
- 解析日: 2026-09-27

## 概要

小学算数ドリル。1マス正解するたびにマスコット・画面演出・BGM が増幅する。ブラウザ完結、課金・ガチャ・ランキングなし。localStorage のみ。

## ドーパミン／快感要素（7レイヤー）

### 1. 即時フィードバック（最小ループ）

- 確定ボタンなし。1桁入力のたびに正誤判定
- マスコット「ドパキチ」が数字を運び、正解で跳躍・拍手、誤答で崩れて復帰
- Web Audio API 合成音（外部音声ファイルなし）。キー・正解・誤答が曲の和音と同期

### 2. セッション内エスカレーション

- 演出強度 `E = 0.08 + 0.92 × (i/(N-1))^1.3`（問題 index ベース）
- BGM テンポ `112 + E×16` BPM、最終問は +2 半音
- 背景・粒子・観客・行進・花火・フィナーレが問題進行と連動
- エクストラモードは `134 + tier×5` BPM でさらに加速

### 3. ドパ + コンボ（数値化された快感）

- **ドパ**: 内部 log10、表示は 100 → 1万 → 1億…
- **コンボ**: 正解マスごと +1、20 コンボでドパ増分 2 倍。得点とは別トラック
- **コンボタイマー**: 学年に応じた制限時間。切れても得点・演出段階は維持
- 節目演出: 10/20/30/50/75/100 コンボ

### 4. 失敗の非惩罚

- ゲームオーバーなし
- 誤答で得点・ドパ・演出段階・BGM は維持（コンボのみ 0）
- 星・トロフィー・演出は失敗・欠席で没収しない
- 2 回誤答→ヒント、3 回目→途中式
- ノーカンハンマーで連続記録を救済

### 5. 中長期の収集・進行

- スキルツリー 58 種、☆1〜5、さびつき（21 日未プレイ）
- トロフィー 306 種（12 分類）、コレクション 47 種 — **ガチャではなくトロフィー報酬で確定解放**
- デイリークエスト 3 つ、ログインシール 7 日周期
- タイムカプセル（30 日以上前の自分の問題が再登場）
- 結果画面「のびたよ！」（前回比 10% 改善）

### 6. エクストラモード（opt-in 高報酬）

- 基本 80% 初回正解率で解放、90 秒制限、得点上限なし
- できた人だけの高強度報酬。強制しない

### 7. 擬似ソーシャル

- 観客・行進・パレード。実ランキング・SNS 連携なし

## 一般化できる原理（蒸留候補）

1. **報酬粒度を細かく** — 完了単位ではなく操作単位でフィードバック
2. **セッション内クライマックス** — 同じ行為でも後半ほど演出・音・テンポを上げる
3. **数値の指数感** — log スケール + コンボ倍率で「伸びてる感」を可視化
4. **失敗は連鎖を切るだけ** — 剥奪・ゲームオーバーにしない
5. **報酬は確定、解放条件は明示** — 教育・習慣系はガチャより「あと N 日で解放」
6. **本人 vs 過去の自分** — タイムカプセル・成長比較（他人比較ではない）
7. **高報酬は opt-in** — エクストラ = できた人のご褒美時間
