# ドパドリル（dopa-drill）— 体験・快感設計の分解

- 出典: https://github.com/grmchn/dopa-drill
- 公開版: https://dopa-drill.tanosix.com/
- 仕様: リポジトリ `docs/SPEC.md`（数式・閾値まで公開）
- 解析日: 2026-09-27
- きっかけ: Product Knowledge 立ち上げの第 1 号参照実装。GK には入れず、体験・コアループ側に分解。

## 概要

小学算数ドリル。1 マス正解するたびにマスコット・画面演出・BGM が増幅する。ブラウザ完結、課金・ガチャ・ランキングなし。localStorage のみ。

**プロダクト名の核心**: 「算数を解くたびに、演出と音楽がどんどん盛り上がっていく」。マスコット「ドパキチ」が数字を運び、正解を祝う。ゲームオーバーなし、まちがえても勢いは落ちない。

---

## 一言で言うと

「ドーパミンハック」というより、**快感の連鎖を壊さない習慣化ゲーム**。スロットマシン型の可変報酬ではなく、**確定報酬のセッション内増幅**。

---

## ドーパミン／快感要素 — 7 レイヤー

### 1. 即時フィードバック（最小ループ）

| 要素 | 実装 |
|---|---|
| 入力即判定 | 確定ボタンなし。1 桁入力のたびに正誤 |
| マスコット | ドパキチが空いている手で数字を運ぶ。左右別々に運べ、判定と運搬を分離 |
| 正解演技 | 跳躍、拍手、回転など |
| 誤答演技 | 崩れてから復帰（10 種、序盤 4 → 中盤 8 → 強度 0.6 以上で 10） |
| 音 | Web Audio API 合成。キー・正解・誤答が曲の和音と同期 |

**原理**: 報酬の遅延を「問題完了」ではなく **1 マス正解** まで短縮。予測誤差（期待と結果の差）が小さな成功単位で繰り返し起きる。

---

### 2. セッション内エスカレーション

基本問題の演出強度（問題 index を `i`、問題数 `N`）:

```text
E = 0.08 + 0.92 × (i/(N−1))^1.3    （1 問だけのとき E = 1）
```

| 連動要素 | 内容 |
|---|---|
| BGM テンポ | `112 + min(1, E) × 16` BPM → 113〜128。最終問は +2 半音 |
| 視覚 | 背景、はなまる、紙吹雪・星・花火・硬貨、観客、行進、電飾、揺れ |
| フィナーレ | 巨大ドパキチ、花火大会、ロケット、パレードから選択 |
| エクストラ | 完了数 `k` → `tier = floor(k/3)`、`E = 1 + min(0.5, tier×0.1)`、BPM `134 + tier×5` |

**原理**: 同じ行為（計算）でも **フィードバック強度が単調増加**。1 セッションにクライマックスを作る。Duolingo ストリークより「1 プレイ内の arc」に近い。

---

### 3. ドパ + コンボ（数値化された快感）

#### ドパ（得点とは別トラック）

- 内部値 `L`（log10）、表示は `10^L` を「万」「億」等で丸め
- 基本曲線: `B(f) = 2.3 × clamp(f,0,1)^1.15`
- エクストラ: `X(n) = 2.3 + 3.0 × (1 − exp(−n/10))`
- 上限: `L = 9.08`（表示上 約 12 億）
- 各入力に最低増分 0.003 — 最初の正解も 1 コンボ・1.05 倍

#### コンボ

| 項目 | 仕様 |
|---|---|
| 加算 | 正解回答マスごと +1。問題をまたいで持ち越し |
| 倍率 | `M(c) = 1 + (2−1) × min(1, c/20)` → 20 コンボで 2 倍 |
| 表示 | 2 コンボ以上。20 以上は「ドパ×2 MAX」 |
| タイマー | 学年 `g`: 通常 `3000+600×(g−1)` ms、最初のマス +2500 ms |
| リセット | 誤答 or 時間切れ → 0（**得点・演出段階は維持**） |
| 節目 | 10/20/30/50/75、100 以上は 50 ごとに大祝い |

**原理**: 可変比率スケジュール（ガチャ）ではなく **確定報酬 × コンボ増幅**。「もう 1 マス」の引き。

---

### 4. 失敗の非惩罚

仕様書の設計思想が明示的:

| やらないこと | 代わりに |
|---|---|
| ゲームオーバー | 続行可能 |
| 誤答での得点・ドパ減点 | 維持 |
| 誤答での BGM・演出リセット | 維持（コンボのみ 0） |
| 失敗・欠席での星・トロフィー没収 | なし |
| 即答の丸写し | 2 回誤答→参照数字強調、3 回目→途中式・九九等 |

**救済**: ノーカンハンマー（所持上限 3）で連続記録をつなぐ。

**原理**: 失敗＝報酬剥奪は離脱を招く。**快感の連鎖を切らない**。教育アプリで意図的に珍しい設計。

---

### 5. 中長期の収集・進行

| システム | ドーパミン的役割 |
|---|---|
| スキルツリー 58 種 | 解放・マスター・☆1〜5 |
| さびつき | 21 日未プレイ → 最大 3 スキルに表示。1 問初回正解で消える（星保持） |
| トロフィー 306 種 | 12 分類・銅銀金虹。プレイ中は獲得ダイアログを開かない |
| コレクション 47 種 | BGM・背景・衣装等。**トロフィー報酬で確定解放（非ガチャ）** |
| デイリークエスト | 簡単 2 + 手間 1。全達成でハンマー 1 本 |
| ログインシール | 7 日周期（プレイ日とは別） |
| タイムカプセル | 30 日以上前の自分の問題が 1 問再登場 |
| のびたよ！ | 前回比 10% 改善を結果画面に最大 3 行 |

**原理**: 短期（1 マス）→ 中期（1 セッション）→ 長期（コレクション）の **3 段報酬階梯**。

---

### 6. エクストラモード（opt-in 高報酬）

- 基本初回正解率 ≥ 80% で選択可
- 90 秒制限、得点上限なし: `100 + 10n + 5n(n−1)/2`（30 問で 2575 点等）
- ドパ・コンボは引き継ぎ（エクストラ開始時コンボ 0）
- 全員強制しない

**原理**: Words For Me の「問い（緊張）→ 答え（作業）→ 言葉（着地）」と同型の **緊張→作業→高報酬**。できた人だけのご褒美時間。

---

### 7. 擬似ソーシャル

- 観客キャラ、行進、パレード
- 実ランキング・SNS・サーバー送信なし

**原理**: 多人数の前でできた感覚を演出のみで再現。

**自社 UGC 文脈との対比**（Growth Knowledge `ugc/`）: Mayu 指摘「視聴者がドーパミン出せるの？」。物語レーンは最後まで見ないと報酬が来ず、その報酬が他人のもの。○選が勝つのは 1 枚目で視聴者の得が確定している。**dopa-drill は本人の入力にだけ報酬が紐づく** — UGC 設計の反例参照としても使える。

## ガチャ型との対比

| | スロットマシン型 | dopa-drill 型 |
|---|---|---|
| 報酬 | 可変・不确定 | 確定・条件明示 |
| 失敗 | 没収・損失 | 連鎖のみ切断 |
| セッション arc | ランダム峰值 | 単調増加エスカレーション |
| 向く領域 | 課金ゲーム | 教育・習慣・子供向け |

**コピーしにくい点**: 1 マス正解が **客観判定** できる。日記・天気・カップル系は判定ロジックを別途設計する必要がある。
