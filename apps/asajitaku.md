# 朝の支度タイマー（asajitaku、仮名）— 体験の採用記録

ADHD 傾向の大人向けの、朝の支度から出発までのタイマー。iOS のみ。仕様は `mayu119/adhd-user-research`（`product/`）、コードは MacBook のローカル repo `~/Downloads/asajitaku-ios`（remote なし）。

## 2026-10-12 見た目とゲームを作り直し

Mayu の指示: 参考は [Steppy](../references/2026-10-11-widget-steppy.md)。ドーパミン周りは PK から取る。

### 採用したもの

| PK の原理 | 出典 | asajitaku での実装 |
|---|---|---|
| 報酬粒度（操作単位） | core-loop | 工程の「できた」ごとに OK! ポップ・四角い粒・矩形波の音・触覚・「+14 XP」 |
| セッション内エスカレーション | core-loop / dopa-drill | 演出の強さ E = 0.08 + 0.92 × (i/(N−1))^1.3（i = 工程の番号）。粒の数・広がり・触覚の強さに連動 |
| 演出強度は音も連動 | feedback | 「できた」の音はコンボが続くほど半音ずつ上がる（8段） |
| 得点と快感は別トラック | feedback | XP（得点）とコンボ倍率（コンボ5で2倍）を分けて表示 |
| 失敗は連鎖を切るだけ | core-loop | 予定+30秒を過ぎた・飛ばした工程でコンボだけ0。XP・成長・アイテムは減らさない。ハートは減らさない |
| デイリークエストは少なく固定 | habit | ハート3つ = 今日のクエスト3つ（間に合う時刻までに始める・コンボ3・予定どおりに出発）。埋まるだけ |
| ストリーク救済は剥奪型を避ける | habit / dopa-drill | CHAIN（出発した日の連続）。クエスト3つ全部の日に「おまもり」1つ（2つまで）、出発しなかった日を自動で1日つなぐ |
| ログインとプレイは別トラック | habit | DAY N（出発した日の累計、減らない）と CHAIN（連続）を分ける |
| 報酬は確定・条件明示／不可逆 | progression | 成長 BABY→KID(300)→TEEN(900)→ADULT(2000)→LEGEND(4000) と、出発回数で増えるアイテム11個を一覧で見せる。没収なし |
| 進歩可視化 | progression | XP ゲージ（Steppy の「XP ■■■····· › KID」）をホーム・結果・もちタブに常時 |
| 本人 vs 過去の自分 / 結果は比較軸を絞る | progression / information | 結果画面の「のびたよ」: いつも（直近5回の中央値）より10%以上早い工程を3つまで |
| 美化記憶・クリフハンガー | core-loop / habit | 結果画面は STAGE CLEAR!・前向きなランク（PERFECT/GREAT/GOOD/CLEAR）・XP の数え上げで締め、NEXT（あと何 XP で次の段階、あと何回で次のアイテム）を残す |
| ピクセル UI は2色 | visual / Steppy | 液晶パネルの中は 地＋ink の2色（キャラの白だけ足す）。既定は「あさやけ」#FFD27A ＋ #2A1E5C。押しているときはパネルが反転 |
| 2書体ルール | visual | 外枠の本文はシステムの文字（Dynamic Type）、数字・バッジ・パネルの中は DotGothic16 |
| 報酬は確定（コスメ解放） | progression | 液晶の着せ替え5色を成長の段階で確定解放（KID メロン〜LEGEND きんいろ） |
| マスコットは overlay | visual | 頭の芽だけが成長で育つ（芽→双葉→三つ葉→つぼみ→花）。からだは不変 |
| 残り時間の体感化（TimeSense の部類） | visual | 液晶の下の地平線で、支度の進み具合に合わせてドットの太陽が昇り、出発の旗に近づく |
| 物理ボタン | visual | 太枠＋下の硬い影、押すと沈む |
| マスコットは overlay | visual | ドット絵のもち（18×18）。形は不変、表情6つ・2コマだけ差し替え。台詞は持たせない |
| 派手さは止められる | visual | 「動きを減らす」で粒・跳ね・点滅を止める。得点は同じ |

### 採用しなかったもの・保留

- 高報酬は opt-in（エクストラ）: 朝は時間が決まっているので入れていない
- タイムカプセル（30日前の自分）: 記録がたまってから
- 残り時間の扇形（TimeSense）: 工程の残りは区切りバー、支度全体は日の出で見せている。扇形は Live Activity・StandBy（M3）で検討

計測（5回到達、CHAIN の続き方、クエストの達成率）は Growth Knowledge の apps に書く。

## 2026-10-12 iOS 感とオリジナリティ

Mayu「色合い変えたりオリジナリティ追加」「iOS 感ももっと」。外枠をふつうの iOS（Liquid Glass のタブバー・ボタン、大見出し、シート、ダークモード）にし、ドットは液晶パネル（角丸のデバイスのカード）の中だけに閉じ込めた。Steppy のライムは着せ替えの1色（メロン）に下げた。

## 2026-10-12 白い外枠をやめて夜明けの空に

Mayu「白い外枠で没入感が削がれる」「iOS らしさがダサさに直結、強みになってない」「ドパれない」。

| PK の原理 | 出典 | 実装 |
|---|---|---|
| body グローバル lv でエスカレート | visual / dopa-drill | 画面全体の空が支度の進み具合で 夜→明け方→朝焼け に変わる。できた！の光・揺れ・粒の強さも工程の番号で上がる |
| リッチ背景は degradable | visual | 空は Canvas のドット描画。「動きを減らす」で星のまたたき・脈打ちを止める |
| 操作単位の即時 FB | feedback | できた！で全画面の光＋揺れ＋中央に COMBO と XP＋画面いっぱいの粒＋音の高さ＋強い触覚 |
| 物理ボタン | visual | 主役のボタンは太枠で沈むドットのボタン（光る）。補助は Liquid Glass |

学び: iOS 標準の白いグループ背景は「設定アプリ」に見え、ゲームの没入を壊す。Liquid Glass は色のある背景の上に置いたときに強みになる。

## 2026-10-13 ロック画面・部屋・ウィジェット

| PK の原理 | 出典 | 実装 |
|---|---|---|
| 操作単位の即時 FB を、アプリの外でも | feedback | Live Activity（ロック画面・Dynamic Island）の液晶パネルで「できた！」。コンボ・ハートがその場で増える。時間切れはパネルを反転 |
| 報酬は確定・条件は明示 | progression | もちの部屋は、まだ無い物を薄い影で置いて「次は◯◯ あと◯回」を出す。手に入れた物は取り上げない |
| マスコットは overlay | visual | ウィジェットのもちは表情だけ朝に合わせて変える（夜は寝る → そろそろ → 始めよう → 支度中 → CLEAR）。からだと芽（成長）は同じ |
| 成長で手に入る物は売らない | progression | 着せ替え5色は成長で解放のまま。買い切りの Pro はアイコン7色と液晶の色2つ（別の色）だけ |

学び: ロック画面の Live Activity は高さ 160pt まで。ボタンの中の数字（「+2分」）はロック画面で「…」に化ける（ヘッダーの文字では起きない）。

## 2026-10-13 初回設定とペイウォールの作り直し

Mayu「ペイウォールとオンボーディングの仕組みも全然だな。PK・GK を参照して」。体験側（PK）で採ったもの。数字の観測は GK `apps/asajitaku.md`。

| PK の原理 | 出典 | 実装 |
|---|---|---|
| 初回は 80 点（全部見せない） | habit / yokubo-no-kpi | 初回設定の中に20秒の「練習ステージ」（3工程の できた！・コンボ・声）。本番の演出（全画面の光・TIME UP 乗っ取り・STAGE CLEAR）は最初の朝に取っておく |
| 5 回到達が習慣化 | habit / yokubo-no-kpi | 5回目の出発のあとに Pro の案内（「ここからが習慣」） |
| 感情の峰に金を重ねない | references dopa-drill（ホンネカード） | 出発の演出の最中には PW を出さず、まとめを閉じてから |
| 権限は理由を先に | information（PermissionSheet） | 許可の画面で「何のために」を先に言い、許可しなくても使えると書く |
| 製品内の案内は UI が語る | information | ショートカットの案内は手順のリストと ShortcutsLink。初出発のあとに1回だけ SiriTipView |
| 結果画面は本人 vs 過去の自分・3行まで | information / dopa-drill | ふりかえり（Pro）は 予定どおりの割合・始めるずれ・遅れやすい曜日 の3つと、のびやすい工程（30秒以上だけ） |
| 感情体力を消耗させない | habit | ふりかえりは「遅れた日も出発できた日」。立て直しは縮める→足りなければ「今日はとばす？」 |

愛着（IKEA 効果）は GK onboarding の原理: 初回設定でもちに名前をつけ、計画の見出し・ペイウォールの見出しに使う。
