# 朝の支度タイマー（asajitaku、仮名）— 体験の採用記録

ADHD 傾向の大人向けの、朝の支度から出発までのタイマー。iOS のみ。仕様は `mayu119/adhd-user-research`（`product/`）、コードは MacBook のローカル repo `~/Downloads/asajitaku-ios`（remote なし）。

## 2026-10-12 見た目とゲームを作り直し

Mayu の指示: 参考は [Steppy](../references/2026-10-11-widget-steppy.md)。ドーパミン周りは PK から取る。

### 採用したもの

| PK の原理 | 出典 | asajitaku での実装 |
|---|---|---|
| 報酬粒度（操作単位） | core-loop | 工程の「できた」ごとに OK! ポップ・四角い粒・矩形波の音・触覚・「+14 XP」 |
| セッション内エスカレーション | core-loop / dopa-drill | 演出の強さ E = 0.08 + 0.92 × (i/(N−1))^1.3（i = 工程の番号）。粒の数・広がり・触覚の強さに連動 |
| 演出強度は音も連動 | feedback | 「できた」の音はコンボが続くほど半音ずつ上がる（8段） |
| 得点と快感は別トラック | feedback | XP（得点）とコンボ倍率（コンボ5で2倍）を分けて表示 |
| 失敗は連鎖を切るだけ | core-loop | 予定+30秒を過ぎた・飛ばした工程でコンボだけ0。XP・成長・アイテムは減らさない。ハートは減らさない |
| デイリークエストは少なく固定 | habit | ハート3つ = 今日のクエスト3つ（間に合う時刻までに始める・コンボ3・予定どおりに出発）。埋まるだけ |
| ストリーク救済は剥奪型を避ける | habit / dopa-drill | CHAIN（出発した日の連続）。クエスト3つ全部の日に「おまもり」1つ（2つまで）、出発しなかった日を自動で1日つなぐ |
| ログインとプレイは別トラック | habit | DAY N（出発した日の累計、減らない）と CHAIN（連続）を分ける |
| 報酬は確定・条件明示／不可逆 | progression | 成長 BABY→KID(300)→TEEN(900)→ADULT(2000)→LEGEND(4000) と、出発回数で増えるアイテム11個を一覧で見せる。没収なし |
| 進歩可視化 | progression | XP ゲージ（Steppy の「XP ■■■····· › KID」）をホーム・結果・もちタブに常時 |
| 本人 vs 過去の自分 / 結果は比較軸を絞る | progression / information | 結果画面の「のびたよ」: いつも（直近5回の中央値）より10%以上早い工程を3つまで |
| 美化記憶・クリフハンガー | core-loop / habit | 結果画面は STAGE CLEAR!・前向きなランク（PERFECT/GREAT/GOOD/CLEAR）・XP の数え上げで締め、NEXT（あと何 XP で次の段階、あと何回で次のアイテム）を残す |
| ピクセル UI は2色 | visual / Steppy | ライム #E4F25E ＋ ink #121509。キャラの白だけ足す。押しているときは画面ごと反転 |
| 物理ボタン | visual | 太枠＋下の硬い影、押すと沈む |
| マスコットは overlay | visual | ドット絵のもち（18×18）。形は不変、表情6つ・2コマだけ差し替え。台詞は持たせない |
| 派手さは止められる | visual | 「動きを減らす」で粒・跳ね・点滅を止める。得点は同じ |

### 採用しなかったもの・保留

- 高報酬は opt-in（エクストラ）: 朝は時間が決まっているので入れていない
- タイムカプセル（30日前の自分）: 記録がたまってから
- 残り時間の扇形（TimeSense）: 今は区切りバー。Live Activity・StandBy（M3）で検討

計測（5回到達、CHAIN の続き方、クエストの達成率）は Growth Knowledge の apps に書く。
